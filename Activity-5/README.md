## 🎀 🦋 Activity Overview 🦋 🎀

> *✨ Prompt Crafting, AI Optimization & Output Comparison ✨*
> 
> 🌸 This activity explores the strategic use of Artificial Intelligence tools and effective prompt engineering techniques.
